# E2E API mock catalog

Every API mock registered for the shared E2E environment, read by
`sync-api-mocks.ts`. One row per `mock-e2e.js` registration, then the shared
helpers it calls, then per-spec mocks grouped by kind. Adding an endpoint is
one row.

Sync: `write:<fixture>`, `spot`, `countries` and `contentful` update the
fixture shape. `report:<shape>` fetches the live API and prints drift without
writing, because tests assert the values. `derived` follows another row.
`skip` is not called, for the reason given.
