SubscriptionController:submitSponsorshipIntents​

Package: @metamask/subscription-controller

Submit sponsorship intents to the Subscription Service backend.

This is intended to be used together with the crypto subscription flow. When the user has enabled the smart transaction feature, we will sponsor the gas fees for the subscription approval transaction.

Parameters:

NameDescription
requestRequest object containing the address and products.

Returns: resolves to true if the sponsorship is supported and intents were submitted successfully, false if the chain does not support sponsorship or the user has already trialed

Handler signature:

(request: SubmitSponsorshipIntentsMethodParams) => Promise<boolean>

SubscriptionController:submitSubscriptionCryptoApproval​

Package: @metamask/subscription-controller

Submits a Shield ERC-20 crypto approval transaction to start or update a crypto subscription.

This handler is Shield / TransactionType.shieldSubscriptionApprove only. Delegation-based products (e.g. Money Account) must call startSubscriptionWithCrypto instead.

Parameters:

NameDescription
requestThe crypto approval request.
request.productTypeThe subscription product. Typed as typeof PRODUCT_TYPES.SHIELD only at the moment (future might support more product).
request.txMetaThe transaction metadata. Must have type TransactionType.shieldSubscriptionApprove.
request.isSponsoredWhether the transaction is sponsored.
request.rewardAccountIdThe account ID of the reward subscription to link.

Returns: void

Handler signature:

(request: SubmitSubscriptionCryptoApprovalRequest) => Promise<void>
