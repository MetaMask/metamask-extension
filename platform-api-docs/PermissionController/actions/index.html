PermissionController:updatePermissionsByCaveat​

Package: @metamask/permission-controller

Updates all caveats with the specified type for all subjects and permissions by applying the specified mutator function to them.

ATTN: Permissions can be revoked entirely by the action of this method, read on for details.

Caveat mutators are functions that receive a caveat value and return a tuple consisting of a CaveatMutatorOperation and, optionally, a new value to update the existing caveat with.

For each caveat, depending on the mutator result, this method will:

  • Do nothing (CaveatMutatorOperation.Noop)
  • Update the value of the caveat (CaveatMutatorOperation.UpdateValue). The caveat specification validator, if any, will be called after updating the value.
  • Delete the caveat (CaveatMutatorOperation.DeleteCaveat). The permission specification validator, if any, will be called after deleting the caveat.
  • Revoke the parent permission (CaveatMutatorOperation.RevokePermission)

This method throws if the validation of any caveat or permission fails.

Parameters:

NameDescription
targetCaveatTypeThe type of the caveats to update.
mutatorThe mutator function which will be applied to all caveat values.

Handler signature:

(targetCaveatType: CaveatType, mutator: CaveatMutator<TargetCaveat>) => void
