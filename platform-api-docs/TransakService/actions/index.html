TransakService:createWidgetUrl​

Package: @metamask/ramps-controller

Creates a Transak payment widget URL through the ramps API proxy (POST {rampsBaseUrl}/providers/{providerId}/widget-url). The proxy injects the partner API key and derives the user IP server-side, so neither leaves the backend. Replaces the OTT flow (requestOtt + generatePaymentWidgetUrl).

Requires both a Transak access token (user must be logged in to Transak) and a MetaMask bearer token from AuthenticationController.

Parameters:

NameDescription
quoteThe buy quote to pre-fill in the widget.
walletAddressThe destination wallet address.
extraParamsOptional additional widget parameters (e.g. theming). Keys must be on the proxy's allowlist or the request is rejected.

Returns: The single-use widget URL (expires after 5 minutes).

Handler signature:

(quote: TransakBuyQuote, walletAddress: string, extraParams?: Record<string, string>) => Promise<string>
